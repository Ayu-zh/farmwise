## 🌾 Krishi Sakhi - AI Agricultural Advisor

Krishi Sakhi is an AI-powered agricultural advisor designed specifically for Kerala's farmers. The platform helps smallholder farmers access government subsidies and schemes through personalized recommendations, multilingual support, and intelligent document analysis. Built with deep understanding of Kerala's unique agricultural landscape—from Kuttanad's rice paddies to Idukki's spice gardens.

###  Problem Statement

Kerala's smallholder farmers face unique challenges in accessing government agricultural schemes:

- ❗ Complex government scheme documentation in technical language
- 💡 Generic agricultural advice that doesn't consider Kerala's unique crops (rice, coconut, spices, rubber)
- 🌐 Language barriers with most platforms only in English or Hindi
- 📄 No personalized recommendations based on farm profile and location
- 🏛️ Difficulty navigating multiple government portals and applications

As a result, many Kerala farmers miss out on relevant subsidies and support programs designed for their specific agricultural context.


###  Our Solution

Krishi Sakhi bridges this gap with an AI-powered platform specifically designed for Kerala's agricultural context:

- 🧠 **AI Document Analysis:** Simplifies complex government scheme documents into easy Malayalam and English summaries
- 🧑‍🌾 **Kerala-Specific Recommendations:** Personalized scheme matching based on crop type, land size, location, and farming practices
- 🌍 **Multilingual Support:** Full Malayalam and English support for true accessibility
- 💬 **Conversational AI Interface:** Chat with our AI assistant about farming queries and scheme eligibility
- 📝 **Guided Applications:** Step-by-step guidance through government application processes
- 🌾 **Local Agricultural Context:** Understanding of Kerala's unique crops and farming challenges

###  Tech Stack

- **Frontend:** React + TypeScript with Vite for fast development
- **UI Framework:** Tailwind CSS with custom Kerala government-inspired design system
- **AI Integration:** Google Generative AI for document analysis and conversational interface
- **Backend:** Node.js with Express for API services
- **Database:** MongoDB for storing farmer profiles and scheme data
- **Document Processing:** AI-powered OCR and text analysis for government documents
- **Deployment:** Modern cloud hosting with mobile-optimized performance  

###  Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Ayu-zh/farmwise.git
   cd farmwise
   ```

2. Install frontend dependencies:
   ```bash
   cd frontend
   npm install
   ```

3. Install backend dependencies:
   ```bash
   cd ../backend
   npm install
   ```

4. Set up environment variables:
   ```bash
   # Create .env files in both frontend and backend directories
   # Add your Google Generative AI API key and other configurations
   ```

5. Start the development servers:
   ```bash
   # Frontend (in frontend directory)
   npm run dev
   
   # Backend (in backend directory)
   npm start
   ```

6. Open your browser and navigate to `http://localhost:5173` to see Krishi Sakhi in action!
